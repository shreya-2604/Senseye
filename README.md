# Senseye

Senseye is a college innovation project aimed at creating a wearable assistive solution for visually impaired individuals. The concept combines a foot-based and belt-based wearable system with real-time environmental sensing to help users navigate more safely and independently.

This repository contains an interactive portfolio website that showcases the product concept, its purpose, key features, and technical specifications in a visually engaging way.

## Project Vision

Many visually impaired users face daily challenges while moving through unfamiliar spaces, crossing roads, or navigating public places. Senseye was designed as a thoughtful assistive technology concept that focuses on:

- improving spatial awareness
- reducing dependency on external devices
- enabling hands-free interaction
- supporting safer movement in real-world environments

## What Senseye offers

Senseye is envisioned as a modular wearable system that combines:

- a belt unit for support and wearable integration
- a foot-based component for movement awareness
- real-time sensing and processing for obstacle detection
- a simple, user-centered design approach for everyday use

The experience presented in this project highlights how the solution can be positioned as a practical and accessible aid for independent living.

## Why this project matters

This project is more than a technical prototype—it is a human-centered design effort focused on inclusion and accessibility. By combining wearable hardware concepts with intelligent perception, Senseye aims to contribute to a more accessible future for people with visual impairments.

This web experience was built using:

- React
- Vite
- Three.js
- React Three Fiber
- React Three Drei
- Framer Motion

## Project Structure

- src/App.jsx — main product showcase experience
- src/index.css — styling and visual presentation
- public/ — 3D model assets and supporting media
- src/assets/ — media files such as videos

## Run locally

1. Install dependencies
   ```bash
   npm install
   ```

2. Start the development server
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal to view the portfolio site.

## Build for production

```bash
npm run build
```
